# 汪汪消消乐 · Bella's Dog Club

一款手机优先、只有狗狗的三消小游戏。原生 HTML / CSS / JavaScript，单人模式完全离线；「双人竞赛」的实时房间需要联网（Supabase Realtime）。

## 开始玩

直接双击 `index.html`，或者开一个本地服务器（方便手机在同一 Wi-Fi 下试玩）：

```bash
cd /Users/michael/Desktop/Bella
python3 -m http.server 4173
# 浏览器打开 http://127.0.0.1:4173 （手机用电脑的局域网 IP）
```

## 页面流程

首页（Mochi、Surprise、Rhea 三位主理狗打头阵）→ 主线冒险（关卡地图 → 关卡说明 → 对局 → 结算）/ 限时冲刺 / 悠闲无尽 / 今日巡逻 / 狗狗成长屋 / 狗狗图鉴 / 怎么玩 / 设置

- **主线冒险**：90 关，九个章节：阳光海滩（Ruby）、雏菊花田（Rhea）、极光雪原（Loki）、泡泡浴室（Waffle）、甜点烘焙坊（Coco）、星光片场（Domino）、学霸书房（Oreo）、霓虹舞厅（Bruno）、森林露营（Noodle）。地图上每章有自己的地标（灯塔、风车、冰屋、浴缸、蛋糕、摄影机、地球仪、迪斯科球、帐篷）、道具装饰、飘动的小动画，章末是 Boss 关（皇冠）和通关宝箱。目标有得分、收集指定狗狗、做技能，每关 1–3 星，进度自动保存。
- **限时冲刺**：开局前先选时长（30 / 60 / 90 / 120 秒）和棋盘：障碍可选 随机 / 不要 / 木箱 / 狗笼 / 混合，形状从「随机」和 13 种形状的样例卡片里挑，卡片上画的就是实际棋盘，「换个摆法」可以换一种障碍摆放。不限步数，引爆技能会加时间。每种时长分别记录最高分，选择会自动记住。
- **悠闲无尽**：不限步数也不限时间，退出时结算并记录最高分。
- **今日巡逻**：每天一张固定棋盘，由日期决定，同一天每个人拿到的题目相同。
- **双人竞赛**：开一个房间，把 4 位房间号或邀请链接发给朋友。两人拿到完全相同的棋盘、狗狗和 60 秒倒计时。对局顶部的比分条实时显示双方分数（数字滚动、+N 飘字）、领先/落后多少、拔河进度条，反超时会闪一下并提示，对手掉线会变灰。时间到比高低。可以再来一局，结算会记录本地胜负场次。
- **首页狗狗游行**：底部一排所有成员循环走过，点一下打开它的图鉴。
- **狗狗图鉴**：十三只狗狗的场景、配饰，可以切换三种表情。

## 狗狗成长屋

从首页的「狗狗成长屋」进入，先从三只候选小狗里领养一只，给它取名字。领养后它会一直住在这台设备的存档里。

- **长大三个阶段**：幼犬期 → 少年期 → 成年期。体型、头身比例和腿长会随阶段变化，幼犬头大身子小，成年后身体更长、腿更高。
- **四项状态**：饱腹、心情、清洁、精力会随真实时间缓慢变化。喂食、摸摸、洗澡、休息、陪玩、散步、训练都会影响状态和成长值。
- **后续体验**：少年期解锁散步和训练。散步会遇到随机小事件（长椅上的老狗、下雨、飞盘……），训练是节奏小游戏，成功后累计训练次数并学会才艺。
- **五个装饰部位**：头部、脖子、背部、爪子、脸部。亲密度升级会解锁更多配饰，每个部位可以同时戴一件，共 16 件：花环、蝴蝶结、皇冠、针织帽、领巾、领结、铃铛、三角巾、小背包、小披风、小翅膀、袜子、雨靴、金手环、圆框眼镜、墨镜。
- **每日心愿 / 连续照顾**：每天有一个小愿望，完成后加亲密度和成长值；连续照顾会累计天数。
- **成长相册**：记录第一次见面、第一次散步、每个阶段、学会的才艺和解锁的配饰，照片会保留当时的成长阶段和穿搭。

## 怎么玩

- 滑动或先后点击两只相邻狗狗交换，3 只同款连成一线就消除；连锁消除有倍率加成。
- 4 连 → 直线骨头（清整行或整列）；L / T 形 → 炸弹骨头（5×5）；5 连 → 彩虹球（清掉场上所有同款）。
- 技能骨头点两下可直接引爆（消耗 1 步）。两个技能互换会触发组合技：直线＋直线＝十字，直线＋炸弹＝三行三列，炸弹＋炸弹＝7×7，彩虹球＋技能＝把同款全变成技能，彩虹＋彩虹＝全屏清场。
- **汪汪大招**：消除会充能，满了点一下，场上会出现三颗技能并连锁爆炸，不消耗步数。连锁动画还没结束时点也算数，会显示「马上开大…」，等棋盘停下自动放出。
- 过关后剩下的步数会变成骨头自动引爆（只加分，星级按过关那一刻计算）。步数用完没过关，可以再要一次 +5 步。
- 每关有 2 次洗牌；没有可走的步时会自动洗牌。6 秒不操作会给提示。

## 形状棋盘和障碍

- **形状棋盘**：方方正正、圆角饼干、钻石、爱心、十字路口、甜甜圈、沙漏、大骨头、小木桥、楼梯、城堡、四格窗、狗饭盆。空洞处没有格子，狗狗会直接穿过去往下掉。
- **木箱**：挪不动，会挡住上面掉下来的狗狗（被挡住的空位由左右斜上方的狗狗滑进来补）。在它旁边消除、或被技能炸到就会碎；**双层木箱**要敲两下。
- **狗笼**：笼子里的狗狗不能交换、不会掉落，但能参与连线；参与一次消除就打开笼子。
- **新目标「拆障碍」**：把关卡里的木箱和狗笼全部清掉。
- 解锁节奏：第 4–6 关开始出现形状；第 7 关木箱；第 12 关狗笼；第 21 关双层木箱和混合摆法。章末 Boss 关一定有障碍。
- 限时冲刺由玩家自己选形状和障碍（见上）；悠闲无尽每局随机一种形状；今日巡逻按日期固定形状和障碍。
- 关卡说明弹窗里有棋盘形状的缩略图，会标出木箱和狗笼的位置。

## 快捷键

`H` 提示 · `S` 洗牌 · `O` 大招 · `P` 暂停 · `Esc` 返回 · 方向键 + Enter 操作棋盘

## 双人竞赛联机

房间使用 Supabase Realtime 的公共频道 `bella-vs-<4 位房间号>`，广播分数、倒计时和结算，Presence 负责谁在房间里。没有数据库表，房间在最后一个人离开后自然消失。

- Supabase 项目通过 Vercel Marketplace 安装，项目地址和 publishable key 写在 `versus-config.js`（publishable key 本身就是给浏览器用的公开 key）。
- 两位玩家收到同一个 seed，用同一套狗狗、同一张棋盘和同一个 60 秒计时；各自的操作互不影响，分数通过 Realtime 实时同步。
- **暂停是两边一起的**：任何一方点暂停（或切到别的 App / 标签页），双方棋盘和倒计时同时冻结。谁暂停谁点「继续」，3 秒倒数后两边按较少的剩余时间对齐再开始。被暂停的一方等超过 60 秒可以选「不等了，直接结算」。
- **掉线自动暂停，可以重新加入**：对手断网、刷新或关掉页面，另一方会自动暂停并最多等 90 秒。比赛进度（房间号、比分、剩余时间）每秒存在本机，5 分钟内重新打开游戏会提示「回到房间」，回去后比分和时间都保留（棋盘会按同一局重新发牌）。两人都在线后任何一方点继续即可。
- **退出比赛**：暂停面板里连点两次「退出比赛」才会真正退出，记一场负；对手立即按「对手退出」结算为胜。
- 胜负场次保存在本机存档的 `versus` 字段里。
- Supabase 免费项目长时间没有请求会被暂停；如果双人竞赛突然连不上，去 Supabase / Vercel 的集成面板恢复一下项目即可。

## 文件

- `index.html`：所有页面和弹窗的结构
- `styles.css`：样式（淡绿、牛油果绿为主色）
- `dogs.js`：十三只狗狗的 SVG 插画（场景、配饰、表情）
- `raise-art.js`：成长屋的全部插画——13 个品种各自的头型、耳朵、尾巴和毛色花纹（幼犬 / 少年 / 成年三种身材，带明暗渐变和毛簇轮廓），16 件装饰品及衣柜图标，以及小屋房间和散步公园两张背景
- `raise.js`：领养、照顾、成长、心愿、相册和装扮逻辑
- `scenery.js`：冒险地图的地标、道具和氛围小动画
- `kit.js`：音效、背景音乐和粒子特效。背景音乐是 `assets/music/puzzle-game-loop.mp3`（Pixabay 免版税音乐 [Puzzle Game Loop](https://pixabay.com/music/main-title-puzzle-game-loop-bright-casual-video-game-music-249201/)，作者 Cyberwave-Orchestra，Pixabay Content License，已转成 128kbps），用 Web Audio 无缝循环播放；直接双击 `index.html` 打开时浏览器读不到音乐文件，会自动改放原来那首代码合成的 bossa 小曲
- `game.js`：消除引擎、模式、关卡、存档和页面切换
- `versus.js`：双人竞赛的房间码、Presence 座位、实时分数、倒计时和结算
- `versus-config.js`：Supabase 项目地址和 publishable key
- `vendor/supabase-2.118.0.min.js`：Supabase 浏览器客户端（本地托管，不依赖 CDN）
- `legacy/`：改版前的旧版本备份
